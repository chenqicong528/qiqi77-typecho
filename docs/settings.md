# 设置说明

后台 **控制面板 → 外观 → 设置外观**。

页面分两栏：左边是分组导航（带搜索框），右边按分组纵向排列。滚到哪儿，左边就高亮到哪儿。

> **留空 = 用默认值。** 不确定的项清空即可，不用填。

## 基础信息（13 项）

| 设置 | 说明 |
|---|---|
| 站点副标题 | 顶栏搜索框的占位文字、抽屉副标题 |
| 备用域名 | 多个域名共用一个站时填，逗号分隔。sitemap 会按访问的域名输出对应地址 |
| 顶栏品牌名 | 顶栏左边显示的名字，留空用站点标题 |
| 站点简介 | 写进 `<meta name="description">`，也显示在侧栏 |
| 头像地址 | 抽屉顶部、启动页、侧栏资料卡都用它。留空用主题自带的 logo |
| 站点图标 | 建议填 `/favicon.ico` 或 32×32 的 PNG |
| 建站日期 | 格式 `2020-01-01`。侧栏显示「本站已硬撑 X 年 Y 天」，**留空则不显示这一行** |
| ICP 备案号 | 填 `粤ICP备xxxxxxx号`，页脚自动加工信部链接 |
| 公安备案号 | 同上，填完整编号 |
| 萌 ICP 备案号 | 萌站专用，不填就不显示 |
| 版权文案 | 支持 `{year}` `{site}` `{name}` 三个占位符 |
| 页脚说明 | 页脚最上面那行小字 |
| 微信搜一搜二维码 | 顶栏二维码图标点开的图，留空则整个入口不显示 |

## 外观与配色（14 项）

### 颜色

**主题色** 决定按钮、链接、标签的颜色。点色块选，或者直接填 `#ff4081` 这种值。

### 圆角与尺寸

| 设置 | 范围 | 说明 |
|---|---|---|
| 圆角 | 0–28px | 卡片和面板共用。0 是直角，28 接近胶囊 |
| 卡片高度 | 160–400px | 首页大图卡的高度，手机端自动减 50 |

### 背景

| 设置 | 说明 |
|---|---|
| 桌面背景图 | 壁纸地址，留空用纯色渐变 |
| 手机背景图 | 移动端单独用一张，留空则沿用桌面那张 |
| **背景图可见度** | **0** 几乎看不到壁纸，**30** 默认，**100** 完全露出 |
| 背景模糊 | 0–24px，配合可见度用。壁纸糊一点更不抢内容 |
| 背景压暗 | 压暗层强度，和可见度叠加生效 |
| 前景不透明度 | 卡片的不透明度。调到 70 以下，壁纸会从卡片里透出来 |
| 顶栏不透明度 | 顶栏毛玻璃的浓度 |
| 卡片遮罩强度 | 封面图上的黑色渐变，封面越花越需要调高 |

### 其它

| 设置 | 说明 |
|---|---|
| 深色时段 | 默认 `19-7`，意思是晚上 7 点到早上 7 点自动切深色。只在「跟随系统」时生效 |
| 正文字体 | 填字体名，比如 `"LXGW WenKai"`。留空用系统字体 |
| 字体文件 | 自带字体的 woff2 地址，和上一项配合用 |

## 首页与卡片（6 项）

| 设置 | 说明 |
|---|---|
| 首页每行卡片数 | 2 / 3 / 4，仅桌面端（≥1024px）生效 |
| 置顶文章 | 填文章 cid，逗号分隔，比如 `1,5,9`。cid 在文章编辑页地址栏 `?cid=xx` 里 |
| 封面来源 | 文章没设封面时怎么补图：`none` 不补（显示渐变）、`random` 用随机图 |
| 随机图地址 | 每行一条，`{rand}` 会被替换成随机数 |
| 卡片显示评论数 | 卡片右下角的评论计数 |
| 顶栏二维码 | 顶栏那个二维码图标，图在「基础信息」里配 |

| 微信 / 支付宝 / QQ 赞赏码 | 图片地址。**三个都空的话，打赏按钮不显示** |

## 抽屉与菜单（5 项）

| 设置 | 说明 |
|---|---|
| 社交链接 | **不用手写 JSON**。下面有勾选面板，勾上填账号即可 |
| 额外菜单 | JSON 数组，`type` 0 是链接、1 是归档页 |
| 抽屉底部图标 | JSON：`{"github":"链接"}` |
| 抽屉署名 | 留空显示默认版权行 |
| 侧栏封面图 | 资料卡顶部那张图 |

社交链接支持：QQ、邮箱、微博、哔哩哔哩、GitHub、Twitter、Telegram、知乎、抖音、网易云音乐。

## 收录与统计（7 项）

| 设置 | 说明 |
|---|---|
| 百度准入密钥 | 16 位 token，从[百度搜索资源平台](https://ziyuan.baidu.com) → 普通收录 → 推送接口拿 |
| 发布自动推送 | 开：发新文章自动推一条给百度（每天 10 条额度） |
| Clarity 项目 ID | 微软 Clarity 统计，留空不加载 |
| Google / 百度 / Bing 验证码 | 各站长平台的 `content` 值，做归属验证用 |
| 统计代码 | 直接输出到 `</body>` 前，放第三方统计脚本 |

### 百度的额度

百度给普通站点 **每天 10 条**。设置页顶部有张「搜索引擎收录」卡片：

- 显示今天还剩多少条
- 「推最近 10 篇」按更新时间倒序推
- 「推全部」会按剩余额度截断，推不完的提示明天继续

配额跨天自动重置。

### sitemap

主题自带 `/sitemap.xml`，**动态生成**，发文章自动更新，不需要手动重建。

包含：首页、全部文章、独立页面、归档页、分类、标签。

提交到各平台时填 `https://你的域名/sitemap.xml` 即可。

## 性能与高级（10 项）

| 设置 | 说明 |
|---|---|
| 静态资源来源 | `local` 用主题自带的文件，`cloud` 走公共 CDN。**国内服务器建议 local** |
| 图片域名替换 | 把文章里的图片地址批量换到另一个域名（比如自建图床） |
| 替换为 | 目标域名，例如 `https://cdn.example.com` |
| PJAX 容器 | 默认 `#qq-shell`，改错会导致无刷新跳转失效 |
| 友链每页 | 友链页分页条数 |
| 友链随机排序 | 每次刷新顺序不同 |
| 自定义 CSS | 输出到 `</head>` 前，直接覆盖主题样式 |
| 自定义 JS | 输出到 `</body>` 前 |
| 页头注入 | 放 `meta`、`link` 这类标签 |
| 页脚注入 | 放统计脚本 |

> 自定义 CSS/JS 属于「后台注入代码」，权限等同于管理员。账号被盗 = 全站被注入，注意后台密码强度。

## 细节微调（12 项）

| 设置 | 默认 | 说明 |
|---|---|---|
| 页面底色 | `#f4f6fa` | 整站背景。深色模式下不生效 |
| 卡片底色 | `#ffffff` | 卡片、面板的背景 |
| 正文颜色 | `#1c1f26` | 标题与正文 |
| 次要文字 | `#96a0b0` | 时间、浏览量、说明文字 |
| 正文字号 | 15.5px | 13–18，步进 0.5 |
| 正文行高 | 1.92 | 1.5 紧凑，2.3 宽松 |
| 内容区宽度 | 1180px | 960–1440 |
| 卡片间距 | 18px | 8–32 |
| 侧栏宽度 | 300px | 240–360，仅桌面端 |
| 顶栏高度 | 60px | 52–80 |
| 阴影强度 | 100 | 0 完全扁平 |
| 头像形状 | 圆角方形 | 可切圆形 |

改配色时建议**只改主题色**，其它颜色保持默认。整套配色是配合调过的，单独改一个容易失衡。

## 备份与恢复

设置页顶部有「配置备份」：

- **备份当前**：把当前所有设置存一份
- **还原备份**：回到上次备份的状态
- **删除备份**：清掉备份

备份存在数据库里（`theme:qiqi77Backup`），不占文件空间。换主题、重装都不会丢。

升级主题前建议先点一下「备份当前」。
