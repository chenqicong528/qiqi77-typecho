# 常见问题

按「现象 → 原因 → 怎么办」排的。找不到你的情况就提 [Issue](https://github.com/chenqicong528/qiqi77-typecho/issues)。

---

## 安装相关

### 1. 启用后整站白屏

**原因**：PHP 版本低于 8.0。主题用了构造函数属性提升和 `match` 表达式。

**怎么办**：面板里把 PHP 切到 8.0 以上（推荐 8.1）。临时看一眼错误可以打开 `config.inc.php` 里的 `define('__TYPECHO_DEBUG__', true)`。

### 2. 外观列表里找不到 qiqi77

**原因**：目录层级多套了一层。

**怎么办**：确认路径是 `usr/themes/qiqi77/functions.php`。如果是 `usr/themes/qiqi77/qiqi77/functions.php`，把里层内容移出来。

### 3. 启用后样式全乱 / 没有 CSS

**原因**：静态资源 404，或者浏览器缓存了旧样式。

**怎么办**：

1. `Ctrl + F5` 强刷
2. 直接访问 `你的域名/usr/themes/qiqi77/assets/css/app.css`，看是不是 404
3. 404 说明文件没传全，重新上传 `assets/` 目录
4. 后台把「静态资源来源」改成 `local`

### 4. 设置保存了，前台没变化

**原因**：主题配置存在 `theme:qiqi77` 这个键下，文件夹名不对就读不到。

**怎么办**：确认文件夹名**正好是** `qiqi77`（全小写）。改名后配置会「失联」，改回原名即可恢复。

## 使用相关

### 5. 打赏按钮不显示

**原因**：三个赞赏码都是空的。

**怎么办**：设置外观 → 文章页 → 至少填一个（微信/支付宝/QQ）。填了图片地址才会显示按钮。

### 6. 顶栏二维码点了没反应

**原因**：「顶栏二维码」开关关了，或者没填二维码图。

**怎么办**：基础信息 → 微信搜一搜二维码 填图；首页与卡片 → 顶栏二维码 打开。

### 7. 侧栏不显示「本站已硬撑」

**原因**：建站日期留空了。

**怎么办**：基础信息 → 建站日期 填 `2020-01-01` 这种格式。留空是刻意隐藏这一行的。

### 8. 背景壁纸看不清 / 太抢眼

**怎么办**：调「外观与配色 → 背景图可见度」：

- 觉得壁纸太淡 → 往 **100** 调
- 觉得壁纸太抢内容 → 往 **0** 调，配合「前景不透明度」降低卡片透明度
- 还可以加一点「背景模糊」，壁纸糊了更不抢眼

### 9. 深色模式不跟着时间切

**原因**：深色时段填的格式不对，或者当前是「强制浅色/深色」。

**怎么办**：格式是 `19-7`（24 小时制，可跨零点）。同时确认右上角的主题开关处于「跟随系统」。

### 10. 评论区的 QQ 头像不显示

**原因**：头像来源选了 `qq`，但访客没填 QQ 号；或者 Gravatar 被墙。

**怎么办**：评论 → 头像来源 改成 `gravatar`，并把「Gravatar 镜像」填成国内可用的地址。

## 收录相关

### 11. sitemap.xml 打开是 404

**原因**：主题不直接生成 sitemap，需要把附带的脚本放到站点根目录。

**怎么办**：把主题目录里的 `extras/sitemap.php` 复制到站点根（与 `index.php` 同级）。放好后：

- 直接访问 `/sitemap.php` 即可看到 XML
- 想让 `/sitemap.xml` 也能访问，加一条重写规则：

```apache
RewriteRule ^sitemap\.xml$ /sitemap.php [L]
```

Nginx 用户需要在站点配置里加：

```nginx
location = /sitemap.xml {
    rewrite ^ /sitemap.php last;
}
```

### 12. 百度推送提示「配额已用完」

**原因**：百度对普通站点每天只有 10 条。

**怎么办**：等第二天。设置页会显示剩余条数，跨天自动重置。急着收录就先推最新的几篇。

### 13. 360 提示「非法 sitemap 路径」

**原因**：提交的 sitemap 域名和 360 里添加的站点域名不一致。

**怎么办**：

- 360 里的站点是 `a.com`，就提交 `https://a.com/sitemap.xml`
- 必须用 `https://`，用 `http://` 会被服务器 301 跳转，校验器可能判失败

## 性能相关

### 14. 首页加载慢

按收益排序：

1. **图片**：封面图压到 200KB 以内，宽度 1200px 足够
2. **静态资源来源**：国内服务器用 `local`，别开 `cloud`
3. **PJAX**：保持开启，站内跳转不重复加载
4. **懒加载**：封面默认懒加载，不要关

### 15. 开了 CDN 后样式错乱

**原因**：CDN 缓存了旧版本的 CSS，或者回源到了备用域名。

**怎么办**：刷新 CDN 缓存；确认 CDN 回源地址是主域名。

## 升级相关

### 16. 升级后设置全丢了

**原因**：升级时文件夹被改名或删了。

**怎么办**：设置存在数据库，不会因为删文件丢失。确认文件夹名还是 `qiqi77`——改名后配置键对不上，看起来就像「全丢了」。改回原名立刻恢复。

### 17. 升级后页面报错

**怎么办**：

1. 后台 → 外观 → 重新点一次「启用」
2. 清一下浏览器缓存
3. 还不行就回滚：`git checkout .` 或重新下载上一版覆盖

升级前建议在设置页点一次「配置备份 → 备份当前」。

## 还是不行？

- Typecho 版本（后台首页右下角）
- PHP 版本
- 浏览器控制台的报错截图
- 出问题的页面地址

有这三样，大部分问题一眼就能定位。

## 子目录安装

### 18. 站点装在 /blog/ 下，CSS 和 JS 全是 404

**现象**：DevTools 里一堆红色，路径是 `https://域名/usr/themes/qiqi77/...`，少了 `/blog`。

**原因**：Typecho 的资源地址 = 「站点地址」+ 主题目录。站点地址填了域名根，程序却在子目录里，拼出来就少一层。

**怎么办**（按顺序试）：

1. 后台 → 设置 → 基本设置 → **站点地址** 改成 `https://你的域名/blog`，保存后回外观重新启用一次
2. 如果站点地址已经正确、还是 404，升级到 v1.0.2+：主题会按当前请求路径自动补齐安装目录
3. 用了反向代理（把 `/blog/` 重写到根）的，v1.0.2 起也能识别，它会对一遍 `DOCUMENT_ROOT` 和程序目录

> 只修资源是治标。文章链接、sitemap、canonical 都依赖站点地址，能改对就改对。

> 配置 Nginx / Apache 伪静态与 PATH_INFO，见 [伪静态配置](rewrite.md)。
